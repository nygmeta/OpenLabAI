# Hardware verification logs

Each file here is written by `scripts/verify_ot2_hardware.py` after it ran
OpenLabAI's OT-2 server against a physical robot. See
[docs/HARDWARE_VERIFICATION.md](../docs/HARDWARE_VERIFICATION.md).

The script refuses to write a run against a test double into this directory.
Logs are committed as written and never edited. Failed runs belong here too.

This directory has no logs until someone runs the script on a real robot.
